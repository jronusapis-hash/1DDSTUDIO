# 1DD STUDIO V6.2

เวอร์ชันนี้แก้เฉพาะ 3 จุดจาก V6.1

1. รุ่น 8,000 บาท เพิ่มคุณสมบัติ “ผมแท้ 100%”
2. รุ่น 15,000 บาท เปลี่ยนข้อความอายุการใช้งานเป็น “ประมาณ 5–8 เดือน” และนำข้อความในวงเล็บออก
3. Before / After เปลี่ยนเป็นสไลด์แบบเดียวกับรีวิวลูกค้า แสดงรูปเต็มด้วย `object-fit: contain` จึงไม่ตัดส่วนบนและส่วนล่างของรูป

## วิธีอัปโหลด GitHub

1. แตกไฟล์ ZIP
2. เข้า Repository `jronusapis-hash/1DDSTUDIO`
3. กด **Add file → Upload files**
4. ลากไฟล์ทั้งหมดภายในโฟลเดอร์ขึ้น GitHub โดยไม่สร้างโฟลเดอร์ซ้อน
5. ใส่ Commit message: `Update website to V6.2 product details and full-image BA slider`
6. กด **Commit changes**
7. รอ Cloudflare Pages ประมาณ 1–3 นาที
8. เปิดเว็บแล้วกด `Command + Shift + R` บน Mac เพื่อรีเฟรชแบบล้างแคช

ส่วนอื่นของเว็บไซต์คงเดิมทั้งหมด
