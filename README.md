## อัปโหลด GitHub
1. แตกไฟล์ ZIP
2. เข้า Repository `jronusapis-hash/1DDSTUDIO`
3. กด **Add file → Upload files**
4. ลากไฟล์ทั้งหมดภายในโฟลเดอร์ขึ้น GitHub (อย่าอัปโหลดโฟลเดอร์ซ้อน)
5. Commit message: `Update website to V6.1 product details and hero cleanup`
6. กด **Commit changes**
7. รอ Cloudflare Pages 1–3 นาที แล้วรีเฟรชด้วย `Command + Shift + R`
