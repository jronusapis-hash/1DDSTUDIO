# 1DD STUDIO V8.0 — Before / After Full Photo

เวอร์ชันนี้ต่อยอดจาก V7 และแก้เฉพาะส่วน Before / After

## สิ่งที่แก้
- กรอบ Before / After บนคอมสูงสุด 900 × 1100 พิกเซล
- แสดงทีละ 1 เคสแบบสไลด์
- ใช้ `object-fit: contain` เพื่อเห็นรูปเต็มทั้งด้านบนและด้านล่าง
- รูปไม่ถูกครอปหัวหรือช่วงล่าง
- มือถือย่อกรอบตามสัดส่วน 900:1100 อัตโนมัติ
- ปุ่มซ้าย–ขวา จุดบอกลำดับ การเลื่อนอัตโนมัติ และการปัดบนมือถือยังคงเดิม
- ส่วนอื่นของเว็บคงเดิม

## วิธีอัปโหลด GitHub
1. แตกไฟล์ ZIP
2. เข้า Repository `jronusapis-hash/1DDSTUDIO`
3. กด `Add file` → `Upload files`
4. ลากไฟล์ทั้งหมดที่อยู่ภายในโฟลเดอร์นี้ลง GitHub
5. ใส่ Commit message: `Update website to V8.0 full Before After 900x1100 slider`
6. กด `Commit changes`
7. รอ Cloudflare Pages 1–3 นาที
8. เปิดเว็บและกด `Command + Shift + R`

## การตรวจสอบหลังอัปโหลด
- เปิดส่วน Before / After
- ต้องเห็นทีละ 1 รูป
- ต้องเห็นทั้งส่วนบนและส่วนล่างของภาพ
- พื้นที่ด้านข้างอาจมีสีดำเล็กน้อย เพราะรักษารูปต้นฉบับทั้งใบและไม่ครอป
